# Product context

Võ Đang Phái LIVE — Kim Đỉnh (Thái Cực & Chân Vũ Kiếm Trận) is a local-first Vietnamese interactive livestream Taoist martial arts / cultivation (Võ Đang / Tiên Hiệp) game inspired by Douyin/TikTok interactive streams. The operator (Chưởng Môn) uses a desktop admin panel (`/admin`) and captures the portrait game (`/overlay`) in OBS (1080×1920). Viewers participate through comment commands (`!quyen`/`!tu` luyện quyền, `!kiem`/`!dan` diễn kiếm, `!dotpha`/`!dokiep` đột phá cảnh giới, `!loithe`/`!daotam <lời thề>` khắc bia môn quy) and optional TikTok gifts (`!lephap`/`!phapbao`); the congregation builds shared sect milestones through the Chân Vũ Trận (Tụ Linh Đại Trận). The local demo works independently of TikTok and visibly identifies simulated data.

Success: coherent Võ Đang Sơn — Kim Đỉnh artwork, Bát Quái Ngự Kiếm Trận orbiting cauldron with celestial qi, circular dais, 10 Cảnh Giới Wudang hierarchy (Đệ Tử Nhập Môn → Ký Danh Đệ Tử → Ngoại Môn Đệ Tử → Nội Môn Đệ Tử → Chân Truyền Đệ Tử → Chấp Sự Đạo Trưởng → Võ Đang Thất Hiệp → Chưởng Pháp Trưởng Lão → Thái Thượng Trưởng Lão → Chưởng Môn Chân Nhân), synchronized controls/overlay, durable SQLite state (`data/vodang.sqlite` on `PORT=3001`), moderated public vows/rules, 40 visible disciples at >=30 FPS on measured hardware (measured 117.70 FPS mean, 47.76 FPS minimum window on Apple M5). Node 24, React 19, Phaser 4.2.1, TypeScript; public/admin contracts live in `packages/shared`. Current broadcaster has phone-only LIVE access; actual desktop broadcasting is a separate requirement.

The authorized extension includes per-LIVE Võ Đang Bảng (Công huân · lễ vật, Tinh tấn · quyền kiếm, Phong thần · đạo hạnh), high-tier gift breakthroughs (Lệnh Bài Võ Đang, Thái Cực Bát Quái Bàn, Chân Vũ Thần Kiếm instant Ngoại Môn breakthrough), a local Vietnamese narrator (Tiên Âm Linh/Đạo Âm), simultaneous-audience milestones and sharing prompts. Free comment actions remain meaningful; gift-board scores are configured contribution points, not currency. All labels Vietnamese. The audience experiences a majestic, mystical Taoist martial arts atmosphere atop Wudang Mountain. See `AGENTS.md` and `docs/IMPLEMENTATION_PLAN.md` for defaults.
